🎬 Movie Engine
A dynamic React movie search application powered by OMDB API.

🚀 Features
🔍 Real-time movie search
⚡ Debounced API calls (500ms)
🧠 Smart UX states:
Skeleton loading UI
Error handling with isolated retry logic
Empty state guidance
🎨 Modern UI using Tailwind CSS (Hover states, flexbox centering)
🔒 Secure API key management via Environment Variables
🛠 Tech Stack
React (Hooks: useState, useEffect, useCallback)
Tailwind CSS
Vite
OMDB API
